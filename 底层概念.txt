一、LLM（大语言模型）
规范定义：LLM（Large Language Model）是基于海量文本训练、通过预测“下一个 Token”来生成语言的大规模神经网络。它的参数在训练后固定，本身不具备记忆、联网或执行能力。
通俗比喻：一个读遍了图书馆、知识渊博，但只活在训练截止那一天的新同事。他不能上网、不能查你公司的文件、不会主动动手，你问什么他就凭“印象”答什么。
核心要点：
本质是一个预测下一个词的概率函数，回答是逐词“接龙”生成的；
知识有截止时间，且不知道你的私有数据；
不会执行操作，只会输出文字；
说出去的话不能回头修改，所以偶尔会“越说越错”。
一句话记住：LLM 是一个很聪明、但健忘且不会动手的文字预测器。


二、Token（词元）
规范定义：Token 是模型处理文本的最小单位。文本先被切分成 Token，再转成整数编号送入模型。Token 不等于字，也不等于词，是介于两者之间的片段。
通俗比喻：模型眼里的文字不是一个个汉字，而是一块块拼图。常见词是一整块，生僻词会被拆成好几块。
核心要点：
中文大致 1 个汉字 ≈ 1.5～2 个 Token；英文约 1 个单词 ≈ 0.75 个 Token；
输入和输出都按 Token 计费，也按 Token 限制长度；
模型看不到字符，只看到 Token 编号，所以有时数不清字母；
代码、JSON、URL 这类符号密集的文本，Token 消耗偏高。
一句话记住：Token 是 AI 的阅读单位和计费单位。

三、上下文窗口（Context Window）
规范定义：上下文窗口是模型单次请求中最多能处理的 Token 总数。它涵盖系统提示、历史对话、用户问题和附加材料的总和。

第 1 轮发给模型： [系统提示] + [问题1]
第 2 轮发给模型： [系统提示] + [问题1] + [回答1] + [问题2]
第 3 轮发给模型： [系统提示] + [问题1] + [回答1] + [问题2] + [回答2] + [问题3]

通俗比喻：这位同事的短期记忆容量。一次只能记住这么多，超出的部分就得忘掉——而且忘了就是真的看不到了。
核心要点：
模型本身没有记忆，“记得上文”是因为程序每次都把历史重新发一遍；
窗口越大越贵、越慢（注意力计算随长度平方增长）；
窗口塞满时，最早的内容会被丢弃，这就是长对话“忘事”的原因；
它决定了你不能把整本书直接塞进去，从而引出 RAG。
一句话记住：上下文窗口是模型一次能看多少内容的上限。

四、Prompt（提示词）
规范定义：Prompt 是发送给模型的全部输入内容，包括系统指令、历史对话、用户问题和附加材料，最终会被拼成一段带特殊分隔符的文本。
通俗比喻：你交代任务的方式。同一件事，说得清楚还是含糊，结果天差地别。
核心要点：
通常由四部分组成：System（角色规则）+ 历史 + 当前问题 + 附加材料；
System Prompt 设定角色和边界，User Prompt 承载具体任务；
好的 Prompt 要说清角色、任务、格式、约束；
Prompt 的质量直接决定输出质量，但救不了模型根本不知道的事。
一句话记住：Prompt 是你怎么问，它决定模型怎么答。

五、RAG（检索增强生成）
规范定义：RAG（Retrieval-Augmented Generation）是一种在生成回答前，先从外部知识库检索相关片段并注入 Prompt 的技术。它把“找资料”和“组织语言”拆成两步。
通俗比喻：给这位同事配一个随时可查的资料柜。回答问题前，先去柜子里翻出最相关的几页，摆在桌上，再照着答——而不是凭记忆瞎说。
核心要点：
流程：文档切块 → 转成向量存库 → 问题转向量 → 找最相近的块 → 拼进 Prompt → 生成答案；
核心价值：不要求模型记住，只要求模型读懂，避免“凭记忆胡说”；
最常见的问题是没检索到对的资料（召回失败），而不是模型不会答；
解决的是“有没有依据”的问题。
一句话记住：RAG 让模型先查资料，再回答。

六、Agent（智能体）
规范定义：Agent 是以 LLM 为决策核心，能调用外部工具、按多步循环推进任务的系统。模型只负责“决定调什么工具、传什么参数”，实际执行由外部程序完成。
通俗比喻：让这位同事从“回答问题”升级为“动手办事”。你说“查下明天天气，下雨就提醒我带伞”，他会自己决定先调天气工具，再根据结果决定要不要提醒。
核心要点：
模型本身不能执行任何操作，只会输出“我要调用某工具”的结构化指令；
真正执行工具的是你的代码，执行结果再回传给模型继续推理；
工作循环：定目标 → 调工具 → 看结果 → 调整 → 继续或结束；
多步调用会快速消耗 Token 和延迟，必须设停止条件防止无限循环。
一句话记住：Agent 让 AI 从“能说”变成“能干活”。

它们之间的关系（三句话）
LLM 是核心，其余都是围绕它的“补短板”：Token 和窗口是它的限制，Prompt 是它的输入方式，RAG 补它的知识盲区，Agent 补它的行动能力。
从上到下是“依赖”关系：没有 Token 就没有输入，没有窗口就装不下 Prompt，没有 Prompt 就没法让 RAG 注入材料，没有工具调用就谈不上 Agent。
从下到上是“能力递进”：光有 LLM 只能聊天；加上 Prompt 能控制风格；加上 RAG 能答私有问题；加上工具和循环才成为 Agent。
记忆口诀：Token 计量，窗口限容，Prompt 下指令，RAG 查依据，Agent 干实事，LLM 是大脑。
